# n00b to console punk

**Beta.** This book is still being revised; tell us what to fix in the [GitHub repository](https://github.com/BooksByGorgo/hacker/issues).

The first book in *way of the hax0r*.
It makes you comfortable with UNIX and Windows shells, terminal applications, command composition, editors, and filesystem work on Windows, macOS, and Linux.
Bash and zsh form the UNIX track, PowerShell the main Windows track, and Command Prompt is covered explicitly rather than assumed away.
Every chapter ends with Key Points, a Level Up section where n00bs can stop and hackers keep exploring, and exercises.
