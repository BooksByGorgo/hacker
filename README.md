# way of the hax0r

Free, evolving books that help students develop hacker skills.
Hacking here means exploring the limits of what is possible in a spirit of playful cleverness, as described in Richard Stallman's [On Hacking](https://stallman.org/articles/on-hacking.html).

The series progression is **n00b → console punk → hacker & modder → guru → 1337 hax0r**.

Read the books at [gorgo.dev/hacker](https://gorgo.dev/hacker/), as web pages, a single-page HTML file, or PDFs.

## Building

Each book directory has a `Makefile`; see [`n00b2punk/README.md`](n00b2punk/README.md) for the requirements.
`build-site.sh` builds the GitHub Pages site under `docs/`, and the workflow in `.github/workflows/pages.yml` publishes it on every push to `main`.

## Contributing

Open an issue or a pull request.
The books are written by people, with AI as a drafting and consistency aid; suggestions from human readers are what make them better.
